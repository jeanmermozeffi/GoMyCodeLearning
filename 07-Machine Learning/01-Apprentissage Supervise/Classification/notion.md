## Classification 

La classification est une technique d'apprentissage supervisé en machine learning qui consiste à attribuer une étiquette 
ou une catégorie prédéfinie à des instances basées sur leurs caractéristiques.

**Principes de Base**
1. Données d'entrée (Features) : Les caractéristiques ou attributs utilisés pour entraîner le modèle. 
2. Labels (Classes) : Les catégories ou classes que le modèle doit prédire. 
3. Entraînement : Le processus d'apprentissage d'un modèle à partir d'un ensemble de données étiqueté. 
4. Test : L'évaluation du modèle sur un ensemble de données non étiqueté pour vérifier sa précision.

**Types de Classification**
1. Classification Binaire : Deux classes possibles. Exemple : spam ou non spam.
2. Classification Multiclasses : Plus de deux classes. Exemple : classification des animaux en chiens, chats, oiseaux, etc.
3. Classification Multiétiquettes : Chaque instance peut appartenir à plusieurs classes. Exemple : un document peut appartenir à plusieurs catégories comme sport, santé, et actualités.
